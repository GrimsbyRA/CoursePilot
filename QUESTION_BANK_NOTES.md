# CoursePilot question bank update

This build adds ten additional authored, subject-focused multiple-choice items to the existing five-item starter set for manual handling, first aid, working at height, COSHH, food hygiene/allergens and forklift/lift-truck training. Other subjects retain their existing starter questions plus a small generic assessment-quality set.

## Important limits
- The builder now uses unique bank items only; it no longer manufactures question count by rephrasing the same five seed questions.
- If the selected count exceeds the available bank, the generated test is reduced to the available unique questions and shows a bank-limit warning.
- This version does not yet contain 50 or 100 validated questions for each subject. Do not advertise those sizes as available for all courses until the relevant bank has been expanded and reviewed.
- All items are draft questions. A competent subject-matter reviewer must verify facts, answer keys, difficulty, outcome mapping, jurisdiction and any awarding-body requirements before formal assessment use.
